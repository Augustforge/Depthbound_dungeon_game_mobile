# План работ MVP

Источник правды по объёму — `docs/GDD.md` (раздел 20). Этот файл — живой чек-лист: агент отмечает сделанное и пишет, что дальше.

**Как получить сборку:** GitHub → вкладка Actions → последний зелёный запуск «CI» → блок Artifacts:
- `depthbound-windows` — распаковать и запустить `Depthbound.exe`;
- `depthbound-macos` — распаковать, открыть приложение через правый клик → «Открыть»;
- `depthbound-android-apk` — установить в эмулятор (BlueStacks / LDPlayer: перетащить APK в окно; Android Studio Emulator: перетащить APK на окно эмулятора).

**Управление на ПК:** WASD — движение (или мышь как палец), Пробел — уворот, 1–3 — навыки, E — действие, Esc — пауза, F3 — debug-меню.
