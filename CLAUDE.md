# CLAUDE.md — как работать с этим репозиторием

Depthbound («Спуск») — мобильный экшен-roguelite на Godot 4.7.2 (GDScript), Android в первую очередь.
Автор общается по-русски; документы и тексты для автора — на русском, код и id — на английском.

## Прочитай перед работой
1. `docs/PLAN.md` — где мы сейчас и что дальше.
2. `DECISIONS.md` — решения агента (архитектура, допущения).
3. `docs/GDD.md` — дизайн-документ; разделы 0, 19 и 20 обязательны, остальное — по задаче.

## Окружение
- Godot ставит `tools/install_godot.sh` (его же вызывает SessionStart-хук). Бинарник: `$GODOT_BIN` или `/home/user/tools/godot`.
- Рендер без видеокарты работает через Xvfb + Mesa llvmpipe (OpenGL 4.5), этого хватает для скриншотов.
- Сеть ограничена политикой окружения: GitHub (git, релизы, raw) и реестры пакетов доступны; Meshy и сайты с ассетами — только если автор их разрешил.

## Команды
```bash
tools/install_godot.sh                 # поставить Godot (идемпотентно)
tools/run_tests.sh                     # все юнит-тесты headless; код возврата != 0 при падении
tools/screenshot.sh <scene> <out.png> [frames]   # отрендерить сцену и сохранить кадр
tools/godot_check.sh                   # импорт проекта + проверка, что скрипты парсятся
```

## Правила кода
- GDScript со статической типизацией, отступы табами, `snake_case`, классы — `PascalCase` (`class_name`).
- Все числа баланса — в `data/*.json` (GDD 19.4), не в скриптах.
- Ни одной строки текста в коде и сценах — только ключи `localization/strings.csv` (`key,en,ru,es`).
- Логика не знает про 3D: она живёт в `World` (`scripts/core/world.gd`) в плоскости этажа и двигается через `World.step(dt)`. Виды (`scripts/view/`, `views/`) читают состояние и сигналы.
- Случайность только через потоки `RngStreams` (seed забега + этаж + имя потока). Никаких `randi()`/`randf()` в логике.
- Пробелы в GDD закрываем самым простым вариантом, ставим `# TODO(design):` и пишем строку в `DECISIONS.md`.

## Проверка перед коммитом
1. `tools/run_tests.sh` — зелёный.
2. Для визуальных изменений — скриншот через `tools/screenshot.sh` и посмотреть его.
3. Обновить чек-лист в `docs/PLAN.md`.

## Арт (Meshy)
- Ключ — переменная окружения `MESHY_API_KEY`; CLI — `npx meshy-cli` (документация: `meshy --help`, всегда `--output-schema v1 --format json`).
- Перед тратой кредитов — `meshy balance` и смета в `art/ASSETS.md`. Каждый ассет записывать в `art/ASSETS.md` (источник, task id, лицензия), промпты — в `art/PROMPTS.md`.
- Риг Meshy — только двуногие. Крыс анимируем процедурно.
